# Code de conduite

Ce projet applique le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

## En bref

- Respecter les personnes, présumer la bonne foi.
- Critiquer les idées et le code, jamais les gens.
- Rester sur le sujet du travail.
- Le harcèlement et les discriminations ne sont pas tolérés, sous aucune forme.

## Signaler un comportement

Écrivez à [formation@spar-x.fr](mailto:formation@spar-x.fr). Les signalements sont traités
de façon confidentielle par les mainteneurs. Pour une faille de sécurité, suivez
[SECURITY.md](SECURITY.md).
