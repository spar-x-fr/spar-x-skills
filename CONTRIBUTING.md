# Contribuer à spar-x-skills

La règle du dépôt : **la qualité avant l'optimisation**. Une contribution est la bienvenue
quand elle améliore le travail et peut le montrer.

## Par où commencer

| Vous voulez | Allez vers |
|---|---|
| Poser une question ou proposer une idée | [Discussions](https://github.com/spar-x-fr/spar-x-skills/discussions) |
| Signaler un bug ou demander une évolution | [Tickets](https://github.com/spar-x-fr/spar-x-skills/issues/new/choose) |
| Signaler une faille | [SECURITY.md](SECURITY.md), en privé |

## Modifier `rightsize`

Suivez [son guide de contribution](skills/rightsize/CONTRIBUTING.md) : installation, vérifications
à lancer et règles propres à la skill. Un changement des règles de routage doit venir avec des mesures.

## Proposer une nouvelle skill

Ouvrez d'abord une discussion dans la catégorie Ideas. Une skill doit tenir dans
`skills/<nom>/`, avec un `SKILL.md`, une licence compatible et son auteur crédité.

## Ouvrir une pull request

1. Créez une branche depuis `main`.
2. Écrivez vos commits en [Conventional Commits](https://www.conventionalcommits.org/fr/) (`feat:`, `fix:`, `docs:`...).
3. Remplissez le modèle de pull request et vérifiez que la CI passe.

Toute participation suit le [code de conduite](CODE_OF_CONDUCT.md).
