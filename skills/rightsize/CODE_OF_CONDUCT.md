# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticise ideas and code rather than
people, and keep discussions about the work. Harassment or discrimination of any
kind is not tolerated.

Report unacceptable behaviour privately to the maintainer through a
[GitHub security advisory](https://github.com/Ayoubhm07/rightsize/security/advisories/new)
or a direct message to @Ayoubhm07. Reports are handled confidentially.
